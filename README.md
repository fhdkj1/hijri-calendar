# تطبيق التقويم الهجري والميلادي (تقويم أم القرى) 🌙

تطبيق تقويم هجري وميلادي تفاعلي بتصميم مطابق للتقويم الإسلامي الكلاسيكي على نظام iOS، تم بناؤه باستخدام **React 19 + TypeScript + Vite + Tailwind CSS**.

## ✨ المميزات الرئيسية

1. **عرض التقويم الهجري والميلادي معاً (مطابق للصورة تماماً)**:
   - عرض الشهر الهجري في الأعلى بالصيغة: `ذو الحجة ١٩-١٢-١٤٣٥ هـ`.
   - ترتيب أيام الأسبوع من السبت إلى الجمعة (RTL).
   - تظليل عمود وخانة اليوم المحدد بلون بيج أنيق (`#cfc5b8`).
   - كتابة اليوم الهجري باللون العنابي المميّز، وأسفله مباشرة التاريخ الميلادي المقابل بالرمادي.
   - تمييز بداية الأشهر الميلادية ببطاقات ملوّنة (مثل شارة `Oct 1` الزرقاء و `Sep 25`).
   - عرض أيقونة **الكعبة المشرفة 🕋** في يوم عرفة (9 ذو الحجة).
   - عرض أيقونة **البالون الوردي 🎈** في يوم عيد الأضحى (10 ذو الحجة).

2. **دفتر المناسبات والورق المسطّر (Ruled Notebook Lines)**:
   - خلفية مسطرة كدفتر الملاحظات في النصف السفلي من التطبيق.
   - قائمة المناسبات والأعياد الإسلامية مع أيقوناتها (يوم عرفة، عيد الأضحى المبارك، رمضان، عاشوراء...).
   - إمكانية إضافة وتعديل وحذف ملاحظات وتذكيرات شخصية لأي يوم محدد مع حفظها تلقائياً (`localStorage`).
   - عرض مواقيت الصلاة الدقيقة (الفجر، الشروق، الظهر، العصر، المغرب، العشاء) حسب تقويم أم القرى.

3. **شريط التنقل السفلي (أيقونات مطابقة للصورة)**:
   - 🌙 **التقويم**: عرض التقويم الشهري المزدوج.
   - 🌐 **المحول**: أداة تحويل فورية ودقيقة ثنائية الاتجاه بين التاريخين الهجري والميلادي.
   - 📋 **المناسبات**: جدول شامل لكافة المناسبات والأعياد الإسلامية للعام الهجري مع خاصية البحث.
   - ⋯ **الإعدادات**:
     - تعديل تقويم أم القرى (-2 إلى +2 يوم) لمطابقة الرؤية الشرعية في أي دولة.
     - التبديل بين الأرقام العربية المشرقية (١، ٢، ٣) والأرقام الغربية (1, 2, 3).
     - التبديل بين هيكل الآيفون الواقعي (شريط STC والبطارية والزر الدائري) أو العرض الكامل.
     - اختيار المدينة لحساب مواقيت الصلاة (مكة المكرمة، المدينة، الرياض، جدة، وغيرها).
     - زر للانتقال الفوري لشهر ذو الحجة 1435 هـ كما في الصورة المرفقة.

4. **دعم كامل للهواتف والحواسب (PWA & Responsive)**:
   - ملف `manifest.json` و `favicon.svg` لتثبيت التطبيق على الشاشة الرئيسية للهاتف أو سطح المكتب.

## 🚀 تشغيل المشروع محلياً

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build
```

يعمل خادم التطوير افتراضياً على:
`http://localhost:5173/`
